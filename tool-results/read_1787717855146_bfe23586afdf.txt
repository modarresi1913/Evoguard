   468→Historical compatibility: 62/100
   469→Dependency compatibility: 58/100
   470→Test compatibility: 83/100
   471→Convention compatibility: 79/100
   472→Security risk: Low
   473→Ownership risk: Medium
   474→
   475→Recommendation:
   476→Review required
   477→
   478→Top evidence:
   479→- الگوی مشابه در دو Pull Request قبلی به rollback منجر شده است.
   480→- API استفاده‌شده deprecated است.
   481→- regression test برای timeout وجود ندارد.
   482→- فایل تغییرکرده مالک مشخصی دارد اما owner review دریافت نکرده است.
   483→```

   485→یک فرمول اولیه ارائه کن، اما به‌صراحت بنویس که وزن‌ها باید با دادهٔ واقعی calibrate شوند.

   488→
   489→```text
   490→Compatibility Score =
   491→w1 * Contract Compatibility
   492→+ w2 * Historical Compatibility
   493→+ w3 * Dependency Compatibility
   494→+ w4 * Test Compatibility
   495→+ w5 * Convention Compatibility
   496→+ w6 * Architecture Compatibility
   497→- w7 * Security Risk
   498→- w8 * Ownership Risk

   504→
